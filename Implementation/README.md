# Month 2 Implementation Evidence

This folder contains the Month 2 DSA implementation evidence for the AI-Based Job Recommendation and Career Guidance Platform.

## Files
- job_recommendation_engine.py — runnable BST, AVL, Graph, BFS, DFS, Max Heap, MatchScore, hashing-style lookup and Merge Sort implementation.
- jobs_users_dataset.json — common job and user dataset.
- pseudocode.md — pseudocode for the workflow.
- test_recommendation.py — automated functional tests.
- sample_output.txt — sample execution evidence.

## Run
python job_recommendation_engine.py

python -m unittest -v test_recommendation.py

The current recommendation score is a transparent baseline based on skill overlap. Advanced weighting and final evaluation are reserved for the final review.
